# Chapter 5: IV. Words and Expressions Commonly Misused

## Core Idea
An alphabetical catalogue of "not so much bad English as bad style, the commonplaces of careless writing." The recurring fix is not word-swapping but "the replacement of vague generality by definite statement" — Rules 16 and 17 applied one word at a time.

## Distinctions Worth Keeping
| Pair | The line |
|---|---|
| aggravate / irritate | add to an existing trouble / vex a person |
| allude / refer | indirect mention / specific one (and *elude* = escape) |
| allusion / illusion | indirect reference / false impression |
| alternate / alternative | every other in a series / one of two choices |
| among / between | more than two collectively / each considered individually |
| compare to / compare with | imply resemblance across orders / point out differences within an order |
| comprise / constitute | the zoo comprises the animals; the animals constitute the zoo |
| disinterested / uninterested | impartial / not interested |
| farther / further | distance / time or quantity |
| imply / infer | the speaker implies; the hearer infers |
| less / fewer | quantity / number |
| lay / lie | transitive (lay, laid, laid) / intransitive (lie, lay, lain) |
| nauseous / nauseated | sickening to others / sick oneself |
| oral / verbal | spoken / word-for-word (so: *oral agreement*) |
| that / which | defining, restrictive / nondefining, nonrestrictive — go "which-hunting" |
| tortuous / torturous | winding / painful |
| partly / partially | a part vs. the whole / to a certain degree |

## Cut or Replace
| Instead of | Write |
|---|---|
| as to whether · as yet | whether · yet |
| case, character, nature (*acts of a hostile character*) | *hostile acts* |
| certainly, very, so (as intensifiers) | a word strong in itself |
| contact (v.) | get in touch with, phone, meet |
| currently | a precise reference to time |
| due to (adverbial) | because of, owing to |
| each and every one | every one of us |
| enthuse | be enthusiastic |
| facility | schoolhouse, prison — name the thing |
| factor, feature | say what actually happened |
| finalize, prioritize, containerize | a verb that already exists |
| he is a man who | he |
| hopefully (= "I hope") | I hope |
| importantly (*more importantly*) | more important, what's more |
| insightful | perceptive |
| in terms of (*unattractive in terms of salary*) | *the salary made the job unattractive* |
| interesting / funny (as announcement) | make it so — don't label it |
| in the last analysis · the foreseeable future | delete |
| irregardless | regardless |
| meaningful, worthwhile, prestigious, thrust | a word that names something |
| most (= almost) | almost |
| one of the most | delete the formula |
| -oriented (*manufacturing-oriented*) | *chiefly concerned with manufacturing* |
| personally, personalize | delete |
| possess | have, own |
| relate to (*I relate well to Janet*) | *Janet and I have a lot in common* |
| respective / respectively | usually omit |
| state (= say) | say — reserve *state* for "express fully" |
| student body | students |
| the truth is / the fact is (as opener) | state the thing |
| utilize | use |
| -wise as pseudosuffix (*taxwise*) | rephrase |

## Grammar Traps
- **and/or** — "damages a sentence." Write *stealing or cheating or both*.
- **but** — unnecessary after *doubt* and *help*. Two *buts* in succession make a reservation to a reservation; rearrange.
- **however** — do not open a sentence with it meaning "nevertheless"; sentence-initial *however* means "in whatever way."
- **like / as** — *like* governs nouns and pronouns; before phrases and clauses use *as*. "Most carefully edited publications regard its use before phrases and clauses as simple error."
- **while** — use only for "during the time that." Replacing *and*/*but*, use a semicolon. Allowable for *although* where no ambiguity results.
- **nor** — after a negative use *or* (*He cannot eat or sleep*) unless paired with *neither*.
- **than** — check for missing words: *closer to my mother than to my father* vs. *than my father is*.
- **this** — referring to a whole preceding clause it often "can't carry the load"; name the referent.
- **unique** — admits no degrees. Not *most unique*, not *very unique*.
- **would** — with *once a year*, *each Sunday*, drop it; the plain past is briefer and more emphatic. In narrative, signal the shift from habit to a particular occasion.
- **noun used as verb** — *gift*, *host*, *chair*, *debut*: "Not all are bad, but all are suspect."
- **participle for verbal noun** — *prospect of the Senate's accepting*, not *the Senate accepting*.
- **they / he or she** — for indefinite antecedents the book offers: pluralize (*Writers must address their readers' concerns*), drop the pronoun, or switch to second person. It rejects singular *they* — a judgment now widely reversed.
- **-ize** — "Never tack -ize onto a noun to create a verb. Usually you will discover that a useful verb already exists."
- **literally** — not for exaggeration: *literally dead with fatigue* → *almost*.
